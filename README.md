# Plant Leaf Disease Detection Script

[![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![OpenCV](https://img.shields.io/badge/OpenCV-Computer%20Vision-green?style=flat&logo=opencv&logoColor=white)](https://opencv.org/)

Standalone Python prototype script for leaf disease identification using image processing and deep learning models.

> 🌿 **Full Chatbot & Vision Project:** For the complete, interactive agritech chatbot application, please visit **[PlantDoc-AI-chatbot](https://github.com/Nikhilesh1228/PlantDoc-AI-chatbot)**.

## 📌 Features
- Leaf contour and image preprocessing via OpenCV.
- Deep learning model inference for disease detection.
- Remote tunnel testing setup via environment configuration.

## 🚀 Usage
```bash
# Set Ngrok authtoken if using remote tunneling
export NGROK_TOKEN="your_ngrok_token_here"

# Run classification script
python copy_of_intern1.py
```
